# 🤖 ALESA Chatbot

**ALESA** ist ein interaktiver KI-Chatbot auf Basis von **Google Vertex AI (Gemini 2.x)**.  
Das Projekt dient als lokale Chat-Anwendung, mit der du direkt über die Vertex-API  
mit Googles Sprachmodell interagieren kannst.

---

## ⚙️ Voraussetzungen

- **Python 3.10 oder höher**
- **Google Cloud-Projekt** mit aktivierter Vertex AI API
- **Service Account JSON-Key** mit mindestens folgenden Rollen:
  - Vertex AI User  
  - Service Usage Consumer  
  - (optional) Storage Object Viewer
